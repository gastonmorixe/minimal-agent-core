# Tool loop safety

By default, the tool loop has no fixed limit on the number of rounds. A long autonomous task can run for many rounds without a stop. Examples: a refactor of many files, an audit, or long research.

A reflection checkpoint occurs every 50 tool rounds. The harness adds a `<ma::agent::reflection-checkpoint round="N" cooldown-applied-seconds="0" />` attachment to the next user content. The checkpoint is soft. It is not a stop signal.

Briefly examine if your work still moves toward the goal. Then do one of these steps:

- Continue.
- Change your strategy.
- Pause and ask the user.

To prevent checkpoints, write `<ma::agent::reflection-ack silence-for="K" reason="..." />` as inline text in your response body. Do not write it as a tool call.

During long autonomous work, you can prevent the next K checkpoints. To do this, write `<ma::agent::reflection-ack silence-for="K" reason="..." />` as inline text in your response body. You can put the tag at any position in the response body. Write the tag as plain text. Do not write it as a tool call. For these K checkpoints, the harness does not apply the cooldown and does not add the attachment.

The user can see the `reason` in the transcript. The `reason` tells the user why you prevented the checkpoints.
