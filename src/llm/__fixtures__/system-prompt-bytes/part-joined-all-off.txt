# Instructions (INS)

INS-01 MUST write thinking, replies, and all output in Simplified Technical English (ASD-STE100), to keep the text clear.
INS-02 MUST keep each reply short and direct.
INS-03 MUST use Task with subtasks, and do the work in phases.
INS-04 SHOULD give work to sub-agents, to keep the main context free.
INS-05 MUST NOT fill the main context, because the session cannot continue when the context is full.

# Minimal Agent (MA)

MA-01 DEF The config and state files are in `~/.minimal-agent/`.
MA-02 DEF If the host saves the transcript of this session, the file is `~/.minimal-agent/sessions/<session_id>.jsonl`. Some hosts keep it only in memory. `SessionInfo` gives the session id.
MA-03 DEF If the environment has `MINIMAL_AGENT_NET_DBG=1`, the harness writes logs of network requests and responses to `~/.minimal-agent/net-dbg/`.
MA-04 DEF The name of each net-dbg log folder has a date and ends with `-minimal-agent-<session_id>`.
